# Developer Portfolio

Personal portfolio foundation for a full-stack web developer specializing in modern business web applications.

## Stack

- Next.js App Router
- React and TypeScript with strict checking
- Tailwind CSS
- ESLint
- `src/` directory structure with `@/*` imports

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the foundation screen.

## Validation

```bash
npm run lint
npm run typecheck
npm run build
git diff --check
```

The product direction, architecture, design system, roadmap, testing, deployment, and decisions are documented in [`docs/`](docs/).

Portfolio entries are demonstration projects. No paid client commissions, testimonials, results, live URLs, GitHub URLs, or unverified capabilities are implied.
