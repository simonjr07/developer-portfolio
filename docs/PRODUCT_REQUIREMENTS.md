# Product Requirements

## Positioning

This product is a personal portfolio for a full-stack web developer specializing in modern business web applications. It is intended to help Upwork prospects, direct business clients, and software agencies understand the developer's approach, capabilities, and demonstration work.

The site must present portfolio entries as demonstration projects. It must not imply paid client commissions or fabricate live URLs, GitHub URLs, testimonials, client results, or technical capabilities.

## V1 scope

- Responsive portfolio foundation in Next.js App Router.
- Routes planned for `/`, `/projects`, `/projects/[slug]`, `/services`, `/about`, and `/contact`.
- Clear project storytelling, service positioning, and contact path in later tasks.
- No database, authentication, payments, CMS, or external app integrations.

## Planned demonstration projects

1. **NexaService** — business website and admin dashboard.
2. **Copper Spoon** — restaurant ordering application.
3. **Aurelia Studio** — booking and appointment application.
4. **Maison Vale** — e-commerce and inventory management.

Only verified details will be added as implementation proceeds. Unknown details will be marked as open content decisions rather than guessed.

## Non-goals for TASK-001

This task establishes the application and documentation only. It does not fully implement the homepage, case studies, forms, or route-specific experiences.
