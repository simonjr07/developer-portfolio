# Deployment

Deployment is intentionally out of scope until explicitly approved. No provider or domain has been configured by this task.

## Public contact destination

The approved public work email is `simonchikaobi.work@gmail.com`. The contact page uses `NEXT_PUBLIC_CONTACT_EMAIL` when configured and otherwise falls back to this approved address. Before deployment, set `NEXT_PUBLIC_CONTACT_EMAIL=simonchikaobi.work@gmail.com` in the intended Vercel Preview and Production environments. This is public information, not a secret. Do not add or overwrite a local `.env` file for this task. Next.js inlines `NEXT_PUBLIC_` values at build time, so changing the Vercel value requires a new build and redeployment. Vercel was not configured or changed as part of TASK-005.1.

## Public site origin and SEO

The SEO implementation uses `NEXT_PUBLIC_SITE_URL` as the approved public origin. Set it to the final absolute origin (for example, `https://your-approved-domain.example`) in the intended Production environment before the production build. Do not commit it to source control or replace a local `.env` file for this task.

This value is intentionally not guessed. Until it is configured, canonical metadata and absolute Open Graph/Twitter image URLs are omitted, the sitemap returns no URLs, and robots metadata/file prevent search indexing/crawling. This avoids publishing localhost, a made-up domain, or a temporary preview URL as the canonical site. Once configured, verify the rendered canonical tag, `/sitemap.xml`, `/robots.txt`, and social preview image on the approved production URL. Rebuild/redeploy after changing the value because `NEXT_PUBLIC_` variables are inlined at build time.

The Open Graph image and site icons are generated by Next.js from source, so no external image asset or third-party image service is required.
